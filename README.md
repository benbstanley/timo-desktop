# Timo for Mac and Windows

Installers for [Timo](https://timocalendar.com), the calendar for you and the people you plan with.

Download the latest version from [Releases](https://github.com/benbstanley/timo-desktop/releases/latest):

- **Mac** (Apple silicon and Intel): `Timo-<version>-mac.dmg`
- **Windows** (x64 and ARM): `Timo-<version>-windows-setup.exe`

Already installed? Timo updates itself.

This repository holds the app installers only. Questions: support@timocalendar.com
